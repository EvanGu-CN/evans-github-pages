## 1. 万豪商务大厦：可用，身份与位置把握高

- 原页：[京东破产拍卖公告](https://paimai.jd.com/notice/14027595)，标题为“沭阳万豪国际大酒店有限公司名下位于沭阳县万豪商务大厦在建工程房地产的土地使用权等”。发布于 **2026-09-29 12:00**；图片拍摄日期未披露。公告所含标的链接：[第5次拍卖](https://paimai.jd.com/311365646)。
- [已实际放大查看的照片](https://img10.360buyimg.com/imgw/s1280x1000_jfs/t1/88953/5/54570/594592/6728419dF785ecd19/d352ee5407fa557f.jpg)。本地 `wanhao-full.jpg`，实际尺寸988×1000。是实景航拍，非效果图。
- 地址交叉证据：[苏州银行官网2022年五一营业安排](https://www.suzhoubank.com/suzhoubank/2022-04/29/article_20241129085958114.shtml)明确沭阳支行在“沭阳县沭城镇苏州西路万豪商务大厦”；照片首层可直接读到“苏州银行 BSZ”。这比同名酒店泛搜可靠。
- [OSM衍生定位](https://mapcarta.com/W1456180564)：way/1456180564，34.11384,118.77072。项目当前同名source outline中心约 **x=-302.0,z=1621.5**，约59×59m，在苏州西路南侧、上海南路西侧。照片正面朝苏州西路，向南观察时左侧大道对应东面的上海南路，位置关系一致。这里是原地同一大厦，没有找到迁址证据。

可建模特征：

1. 主塔是方正、米灰色石材/瓷砖面板的宽矩形体；中央有窄竖向凹槽，两边方窗成规则网格，不能做成全玻璃塔。
2. 我从正面照片数到主楼约 **20层可见窗排，误差±1层**，其中顶部约2层有退台/装饰处理。裙楼明确可见 **4层**：首层银行及商铺，上面3排较大的玻璃窗。总计约 **24±1层**；这是照片估计，不是竣工图的层数。
3. 裙楼比塔楼宽，粉灰/棕灰墙垛之间是大块深色玻璃。裙楼屋顶有设备、空调及少量绿化；塔楼在裙楼上略后退。
4. 顶部做两侧退台，中段升高，外缘有矮实墙和两端小方柱；无尖顶、无穹顶。
5. 沿街入口前有台阶和停车区；银行白底绿字横招很有识别性。不能把京东水印制成建筑贴图。

建模高度建议：若必须先定比例，可用 **85–100m的照片示意范围**，再由主程序选择保守值；这是“层数×假设层高+顶部”的近似，**不是实测高度**。当前source记录h=17.8m与照片的20余层体量明显不符，不宜照搬。

## 2. 久盛百货：只采用可对应主盒体的西侧实拍

- 原页：[我苏网《沭阳这些老广场换“新装”啦，颜值超高！》](https://www.ourjiangsu.com/a/20190929/1569742645931.shtml)，**2019-09-29 15:31:33**发布，来源标注沭阳发布。照片有“沭阳发布”水印，摄影日期未单列，属于2019年时点实景。
- [西广场远景](https://upload.sq1996.com/2019/0929/1569717854132.jpg)，本地 `jiusheng-west.jpg`。
- [西侧蓝玻璃转角近景](https://upload.sq1996.com/2019/0929/1569718109424.jpg)，本地 `jiusheng-west2.jpg`。
- [东广场邻栋照片](https://upload.sq1996.com/2019/0929/1569718260785.jpg)，本地 `jiusheng-east.jpg`。三张均已实际查看。
- 项目source **way/1367632165** 主轮廓为 `[110,-33.5,122.5,-99.5,59,-110.5,47,-44.5]`，中心约 **x=84.8,z=-72.0**，约75.5×77m，位于人民中路/上海中路路口东北侧。
- [地址旁证](https://m.icauto.com.cn/tcw/115848.html)列“人民中路24香港久盛百货”。该聚合站页面其他附近停车场/城市标签可能有错，地址只能作为辅助；主要依据是沭阳发布的明确“久盛百货西广场”图注、方形商场外观和真实source的位置关系。

主盒体建模依据（高把握）：

1. 西侧是约 **3层量级的低矮方盒商业体**，挑高和设备层无法从照片精确分离；不要照邻栋做成7层黄楼。
2. 顶部连续白灰色檐口/女儿墙，带细水平线；檐下主要是深棕色密集横向百叶。
3. 靠路口的直角转角由一条突出、竖向通高的蓝绿色玻璃体强调；幕墙有清晰的方格分缝，底部有黑色环绕腰带。
4. 上部大块广告牌/屏幕嵌在白色矩形边框内；首层沿街是连续透明门店、白色横向招牌带。
5. 前方有较开阔人行广场、树池、路灯。照片中的手机品牌只反映2019年的租户，不应宣称是2026年的现租户。

**东广场图的黄褐色、约6–7层、弧形转角并中央横条玻璃的建筑，不应套到way/1367632165上。** 本地source还有南侧相邻way/995943494（中心约113.5,-12.2，约61×33.5m）等独立建筑；相邻关系支持“不同楼体”的判断，但尚不能仅凭这几张照片把东广场黄楼精确绑定到某个way。因此本轮只建议重建西图的主盒体，不为邻栋分配未经确认的立面。

## 3. 县中医院、人民路旧院与中医大厦：已看图，必须分开

- 实际查看了[百科页面](https://m.baike.com/wikiid/8917680364442827932)给出的[县中医院照片](https://p3-sdbk2-media.byteimg.com/tos-cn-i-xv4ileqgde/fdd86f7639974f6da10d1cebd86d9669~tplv-xv4ileqgde-resize-w%3A1440.image)，本地 `tcm.jpg`。拍摄日期不详，图中仍写“国家三级乙等中医院”，不能当2026最新标识。
- 图上“沭阳县中医院”院名可直接辨认；多份医疗目录将现院地址列为 **上海中路28号**，例如[2024版医疗机构清单](https://static.zhongan.com/upload/online/material/1722843627409.pdf)。地址证据是目录，图片来源是百科，可靠性应分别看待。
- 图中外观：高层浅灰塔楼配水平玻璃窗带；下方约5层、浅蓝灰玻璃面板的长条临街裙楼；裙楼中央挖出高大的车辆/行人穿越门洞，浅色石框加红色院名；街边有连续公交候车棚。它是实景，不是效果图。
- 项目另有 **way/1086134484“中医大厦”**，中心约134.2,155.8，source轮廓约82.5×63.5m。住宅交易页面和历史裁判文书另有“中医大厦东单元601室”的表述：[历史裁判文书](https://cn.govopendata.com/caipanwenshu/2017/03/21/0c219507-b24d-41ca-a31a-74255beae23c/)。
- **结论：实景照片可用于核对上海中路28号现院，却不能据此确认人民路旧院或同名住宅“中医大厦”的外观。** 同一医院资料还有“36层中医大厦”称呼，可能涉及不同楼体/阶段，本轮没有把它强行绑定到source。人民路旧院仍缺可靠、可定位的正面实拍，暂不定制。

## 建议接入顺序与证据限制

1. 优先万豪：照片体量和现有17.8m source高度冲突明显；保留真实outline，改为米灰方窗高层+4层商业裙楼，楼层和高度标为照片估计。
2. 其次久盛：只用西侧低盒体外观；不把东广场黄褐邻栋合并进同一source。
3. 医院、沭阳大厦、维也纳、花都暂保留源几何与适合用途的保守材质，待取得可定位实拍后再改。当前确认的上海中路28号医院照片仅作新旧址排除证据。
