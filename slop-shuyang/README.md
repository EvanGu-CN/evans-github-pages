# Slop 沭阳

用 [three.js](https://threejs.org/) WebGPURenderer 与 TSL 着色器搭建的江苏沭阳 3D 城市仿真，按 1 单位 = 1 米组织沭阳城区：人民路、上海路、北京路、苏州路、迎宾大道等道路，新沂河/淮沭河/柴沂河与城区河道，街区建筑、公园绿地，以及 21 处可传送地标。

只渲染城区核心：东西约 6.6 km、南北约 7.4 km，约 48.8 km²（北到台州路森林公园/城北公园，南到学院路体育中心/南湖，西到八一广场，东到虞姬公园/政务中心）。乡镇、村庄和开发区远端不纳入。

支持步行、驾车、骑行、直升机四种出行方式，第三人称跟随、低角度追车、驾驶舱、多处风光机位与自动巡游航拍，以及实时小地图和全屏街道图。

本项目是 [Slop New York](https://github.com/mrdoob/slop-newyork/) 的城市替换版：保留其渲染、交通、行人和音频引擎，把城市内容层从曼哈顿换成了沭阳。城区范围、代表地标清单与加载策略参考了 [Slop 武汉](https://github.com/LightYearZh/slop-wuhan) 的做法。

## 地图（纯矢量 A 方案）

小地图与全屏街道图直接用 3D 城市同一份 OSM 数据绘制，不依赖外部瓦片，离线可用：

- 水面多边形、河道中心线、公园与绿地
- 机动车道、步道、自行车道、小路、桥梁、铁路
- 7,558 栋 OSM / Overture 来源建筑轮廓（保留内院，高亮较高建筑）
- 21 处代表地标与 120 个具名建筑 / 地点，按政务、商业、学校、医院、文化、办公等分类显示
- 道路名、公园名、水体名、社区/村庄名，带标签避让
- 141 个真实小区名称与边界，按名称或已有别名搜索并高亮范围；小地图和三维场景同步标注
- 搜索小区、道路、建筑、POI、公园、地名
- 搜索结果可直接打开高德 / 百度地图核对同名地点（外部网站需要联网）
- 比例尺、城区边界、`© OpenStreetMap contributors · ODbL` 署名

地图与 3D 共用 `js/shuyang-geodata.js` 的坐标与要素，不存在两套地图对不上的问题。

## 运行

公开站点：[沭阳漫游](https://evangu-cn.github.io/evans-github-pages/slop-shuyang/)。部署仓库为 [EvanGu-CN/evans-github-pages](https://github.com/EvanGu-CN/evans-github-pages)，使用 `main` 分支下的 `slop-shuyang/` 目录。该目录的 `deployment-manifest.json` 记录来源提交及运行文件校验值。

台州路珠海路—杭州路已按2022年标准断面与通车后实景细化为21.5米双向六车道，并补两侧分隔绿带、非机动车道、步行带和路缘；三维、地图与车流共用道路几何。照片拍摄日未知，路口和植栽铺装仍为展示估计，详见[验收与来源](docs/acceptance/taizhou-corridor-2026-11-15/README.md)。

项目是纯静态页面，不需要构建：

```bash
python -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

或者用任意静态文件服务器托管仓库根目录。需要支持 WebGPU 的浏览器（Chrome / Edge 113+，Safari 18+）。

## 操作

| 按键 | 功能 |
| --- | --- |
| `1` / `2` / `3` / `4` | 步行 / 驾车 / 骑行 / 直升机 |
| `W` `S` `A` `D` | 移动 / 转向 |
| 按住 `Shift` / 点击“加速” | 临时加速 / 切换持续加速（四种方式均可用） |
| `Space` | 跳跃 / 刹车 / 上升 |
| `M` | 沭阳城区街道图 |
| `V` | 切换机位 |
| `H` | 隐藏界面 |
| `N` | 静音 |
| `B` | 鸣笛 |

本地演示可用 `?tp=<地标id>` 直接落到某地，例如 `http://127.0.0.1:8123/?tp=shiyan` 打开即到沭阳实验小学校门口；`?tp=mengxi`、`?tp=workersPalace` 等同理。

移动时左上角常驻方位图，固定上北下南，黄色箭头显示朝向；点击小地图打开城区全图。触屏摇杆和动作按钮保持在下方，右侧“加速”可切换持续加速。骑行模式还提供“刹车”按钮。

传送菜单底部“小区实景与入口”可查看147个具名小区范围的资料状态，其中18个有已核对照片；沃德嘉园庭院照片未见题名，已单独说明。4处入口/景石按地图交点近似建模，其余门址仍待定位。可前往已识别的地图通行口。持续进度见 [还原进度](docs/BUILDING_REFINEMENT_PROGRESS.md)。

传送菜单底部“查看地标实景参考”可切换21处地标的实拍、来源和年份说明。照片用于形体与材质参考，未将来源照片贴满三维建筑。拍摄日未标注的图片不推定为2026实景；完整记录见 [实景核对与验收](docs/acceptance/photo-landmarks-2026-11-12/README.md)。

高德 Web/JS key 已用于本地核对地标身份、照片及官方卫星/标准地图图层；安全密钥仅在临时代理进程内存使用，不进入网页或数据文件。已保存的公开地点资料不含密钥，日常漫游无需调用高德。

## 重新生成数据

已包含裁剪后的来源文件，日常离线重建：

```bash
python -m pip install -r tools/requirements-buildings.txt
python tools/build-shuyang-reviewed-district.py
python tools/build-shuyang-reviewed-water.py
python tools/enrich-shuyang-buildings.py
python tools/build-shuyang-urban.py
python tools/build-shuyang-landmarks.py
python tools/build-shuyang-communities.py
node --max-old-space-size=8192 tools/build-shuyang-geodata.mjs
```

首次下载或更新数据的方法见 `tools/data/shuyang/BUILDINGS.md`。

脚本会写出：

- `js/shuyang-geodata.js` — 道路、路网图、街区、水系、公园、用地、地标与地名
- `js/building-geodata.bin.gz` — SYB2 压缩建筑（7,741 条，含用途、高度来源、底部标高、层数及内院），供 `js/building-geodata.js` 解码

管线包含：

1. 经纬度 → 世界米制坐标（等距圆柱局部切平面）
2. 道路去重、端点聚类成路网图，按宽度/车道/单行生成车道
3. 以 3 m 栅格把车行道从陆地中切出，连通域即路缘岛（街区），再生成地块矩形
4. OSM 标签优先，Overture 按实际多边形重叠去重；内院、多部件和来源属性保留。高度优先使用标签/层数，再采用匹配的模型或 CNBH 有效像元中位数，最后按用途估计
5. 默认仅使用来源轮廓，关闭街区随机补楼；住宅不随机套办公幕墙，商铺仅在商业建筑临街面生成
6. 水面多边形与河道压入 30 m 地面栅格，形成下沉河床与河岸挡墙
7. 地标 POI 与 OSM 建筑匹配，结合 `js/city-config.js` 的 21 处代表地标配置输出模型定位与地块保留区
8. 地标保留区内清除公园树与普通楼栋，保证牌坊、塔楼、体育场等主体不被遮挡
