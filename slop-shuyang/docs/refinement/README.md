# 城区持续核对清单

目标保留现有城区全范围：全部7,741条建筑来源、1,104条道路及92条地图步道。不能用少数地标或一个街区的测试通过，推断全城区已经完成实景还原。

这里的条数只是现有来源清单，不能当作现实城区建筑已经全部收录。八一邓园/幼儿园的轮廓冲突、吾悦东侧遮挡候选和其他尚未入库的楼体，仍按[持续进度中的缺口](../BUILDING_REFINEMENT_PROGRESS.md)继续调查、补录；目标不限于给现有7,741条记录加外立面。

`coverage.json`逐条登记来源ID、位置、建筑类别、模型绑定及实景登记状态，并按600米网格整理待核对对象；`summary.json`为统计。运行 `node tools/audit-photo-refinement.mjs` 可从当前来源重新生成。

目前状态表示：

- `photo-frontage-estimate`：有单条建筑的实拍身份与立面样式登记，尺寸仍可能估计；本批维也纳仅一面，其他三面未核对。
- `model-bound`：现有专用模型明确绑定此来源记录。不是所有立面均有照片，也不是测绘精度认证。
- `not-yet-inventoried`：尚未纳入本清单的逐栋证据登记，**不等于没有渲染细节**。此前沃德、学校等叠加模块尚需逐栋补入登记，不能把登记数当作真实完成率。
- 道路 `partial-frontage-reference` 只表示部分街段的一侧有照片样式参考；广场路约100米的一侧不代表整条路完成。其他道路和步道继续待核对。

后续按核心商圈、沿街建筑、道路界面与相邻街块持续推进，先补定位、照片时点和来源绑定，再细化轮廓、材质、门窗、檐口、屋面与步行设施。不能定位的图片、同名异地建筑和效果图均不作为完成证据。
