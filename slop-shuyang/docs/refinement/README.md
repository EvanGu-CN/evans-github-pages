# 城区持续核对清单

目标保留现有城区全范围：全部7,742条建筑来源、1,104条道路来源way（现为1,105条渲染分段）及92条地图步道。台州北路在项目边界切分，分段数增加不代表新增物理道路。不能用少数地标或一个街区的测试通过，推断全城区已经完成实景还原。

这里的条数只是现有来源清单，不能当作现实城区建筑已经全部收录。八一邓园/幼儿园的轮廓冲突、吾悦东侧遮挡候选和其他尚未入库的楼体，仍按[持续进度中的缺口](../BUILDING_REFINEMENT_PROGRESS.md)继续调查、补录；目标不限于给现有7,742条记录加外立面。

`coverage.json`逐条登记来源ID、位置、建筑类别、模型绑定及实景登记状态，并按600米网格整理待核对对象；`summary.json`为统计。运行 `node tools/audit-photo-refinement.mjs` 可从当前来源重新生成。

目前状态表示：

- `photo-frontage-estimate`：有单条建筑的实拍身份与立面样式登记，尺寸仍可能估计；维也纳与政务服务中心都只细化一侧主立面，其他立面未按实拍定制。
- `photo-height-and-facade-grid-estimate`：中央商城大厦保留150米原来源，以消防报道147.15米及14/29层信息和实拍窗格类型细化展示；均匀层高、网格和朝向仍估计，完整楼顶未核实。中央商场裙房另按有限北侧入口登记，不代表其他面已核实。
- `photo-canopy-detail-estimate`：蓝天商贸城仅按具名拍卖实拍细化单层门架、圆洞和条形天窗；尺寸、数量、南侧门位仍估计，原来源主体保留，不能当作整座市场实际屋顶轮廓已还原。
- `model-bound`：现有专用模型明确绑定此来源记录。不是所有立面均有照片，也不是测绘精度认证。
- `photo-massing-and-frontage-estimate`：博物馆/图书馆按卫星可见屋顶范围与具名实拍细化主体和一侧主立面；位置、朝向与高度仍有解释和估计，`geometryEvidence`保留方法、来源、时点与限制。
- `photo-plan-and-massing-estimate`：美术馆按设计方总平面及建成实拍细化分散体块，仍拟合在来源地块内；曲面与尺寸不是竣工测绘。
- `imagery-roof-detail-estimate`：从可见影像补录缺失建筑并细化屋顶，地面立面仍为通用表达；档案馆身份按官方相对地址推定，没有核实的街面实拍，不算立面已还原。
- `not-yet-inventoried`：尚未纳入本清单的逐栋证据登记，**不等于没有渲染细节**。此前沃德、学校等叠加模块尚需逐栋补入登记，不能把登记数当作真实完成率。
- 道路 `partial-frontage-reference` 只表示部分街段的一侧有照片样式参考；广场路约100米的一侧不代表整条路完成。其他道路和步道继续待核对。
- 兰亭路和承晖路的4条分幅来源登记`frontageReview`：文化馆群相邻一侧的窄铺装/绿带按建成鸟瞰及卫星图近似细化，保留具体来源ID、范围、面积和限制；两条路的其他部分及车道断面没有因此通过验收。
- 道路 `photo-standard-section-estimate`：台州路三条主路来源按施工单位标准断面及2022年通车后实拍细化；标准路段可交叉核对，路口变化、铺装和植栽仍为展示估计，不代表逐段现状验收。`sourceWayId`保留道路来源，`profileReview`记录原宽度/车道与本次展示值。

后续按核心商圈、沿街建筑、道路界面与相邻街块持续推进，先补定位、照片时点和来源绑定，再细化轮廓、材质、门窗、檐口、屋面与步行设施。不能定位的图片、同名异地建筑和效果图均不作为完成证据。
