# 持续还原进度

更新于2026-11-13。目标仍是尽量补齐城区楼体、街道与小区，并按可核对的实景细化地标。**当前没有完成全城逐栋现状还原**；来源记录数量、影像服务版本和测试通过都不能作为完成依据。

## 当前结果

- 建筑来源共7,728条：OSM 1,425、Overture 6,133、人工核对影像/在线图层补录170。原有7,558条全部保留。普通楼体实际渲染7,697条，30条由明确绑定的专用模型承载、1条完全被模型覆盖；13条只裁去重叠部分，裁剪失败0。
- 吾悦周边前批90处逐个核对的屋顶候选，排除29处重叠，补入盛源金城23、临安小区9、阳光天地南部13、嘉瑞·玫瑰园16处近似轮廓。嘉瑞本批改为多顶点外沿，另5处东侧遮挡候选仍延后；2处与旧小轮廓冲突，已保留冲突ID与面积，不能当作该处完整楼体已复原。**不是吾悦周边已经全部补齐**；本批继续补了幸福家园、君临天下，附属建筑与邻近商住片区仍有缺口。
- 盛源金城、临安小区增加中文导航名称和近似街区范围。两者不是正式小区红线；包含的27/96条源记录也不是已逐栋核实的实际楼数。实拍确认的多层住宅采用浅米色/橘红白色系；不将这一配色套给未核对的高层、厂房或办公楼。
- 已标注147个具名小区范围，共关联3,195条建筑记录。此前141个小区的高德公开地点查询完成，131个名称与位置匹配，127个有候选图片；盛源、临安两个近似范围尚未补做地点查询；华辰、幸福家园已完成本次具名地点核对。
- 18个范围已核对实拍参考；沃德嘉园照片未见题名，身份仍有不确定性（幸福家园主区与一期共用身份照片），4处入口/景石模型保留；其余14个范围的具体门址未定位。原141个小区查询的候选地点图共308张，已排除上海夜景和嘉瑞楼盘效果图。地点图片不等于建筑外观确认，未标拍摄年的不当作2026现状。
- 20处可传送地标包含梦溪中学、大润发、吾悦广场、沭阳高级中学及新增的老虞姬公园。公园路19号的虞姬公园（城北公园）、迎宾大道虞姬生态园、南湖内虞姬园三处名称分开。
- 南湖补录约9.20万平方米近似水面，保留岛屿、半岛及南北两处可辨广场。四座地图标记的步行桥沿来源线位生成，可步行/骑行通过，汽车不驶入。桥面高程和栏杆细节仍是展示估计。
- 南湖水面、草坪、地面、小地图与通行判断共用有岛屿孔洞的几何。局部岸线用精确多边形替换30米地面格子；公园树木避让水面、广场和运动场。移除了未定位而任意摆放的南湖通用亭桥、展馆和雕像，实拍参考保留。
- 五里公园运动场补录平滑红色环形跑道、绿色内场、内场边缘、西侧6块矩形球场及周边铺地，共10个地表几何；3D与地图共用，场地名称正确归类为体育。项目类型和道数未知，不补虚构篮架/足球线/跑道道数。
- 沭阳高级中学校内来源运动场地已显示；新增2025年公开的大礼堂实拍参考，尚未把它强行绑定到无名教学楼。保留23条源校园楼体与内院。
- 其余本轮成果继续保留：县政府斜向主楼与西侧附楼、体育中心南北向露天主场和两馆、中央商城147.15米来源主塔、完整商场轮廓、万豪与久盛实拍参考模型；中文界面、小地图和持续加速均可用。

本批新增54条建筑来源：君临天下27条（含24个独立楼号、1组北侧连体轮廓与2处附属），幸福家园24条，华辰3条完整底图轮廓。华辰显示四个高层体块，78米及西侧8米低连接部为估计；旧局部来源记录保留，明确绑定同一新模型。另补7段内部通行路，较大幸福家园主区与较小1期范围分开。详见[前批验收](acceptance/junlin-huachen-2026-11-13/README.md)。

## 后续优先补齐

1. 优先继续改善已补住宅的实际屋顶和外立面：当前复杂/凹轮廓的坡顶显示仍不完整，不能将数据中的gabled标记当作已经重建真实坡面。
2. 嘉瑞仍需处理5处遮挡边界、2处旧轮廓冲突及内街；碧桂园、新世界商业广场等相邻片区仍缺楼。幸福家园与君临天下的附属设施、内街和景观细节继续核对，不按规则网格造楼填空。
3. 129个小区范围尚未逐张核对实拍；14个已有实拍的范围仍需定位门址。308张候选图大多尚未逐张核验，两个新小区尚未补做高德查询。
4. 南湖花瓣平台、园内建筑、门楼、雕像与栏杆真实样式尚未完整定位；当前绿化是示意布点。老虞姬公园纪念塔与石桥已取得实拍，但园内锚点未确认，不能放到虞姬生态园或随意摆放。
5. 高中大礼堂、育华楼与不同教学楼的照片—轮廓对应仍需核实；不能全校统一层数。政府主塔、场馆屋盖等精确高度仍缺可靠测量。
6. 继续补旧医院、沭阳大厦、维也纳购物中心、花都大厦等具名非住宅的现状照片；不将异地同名商场、效果图或新院套到旧址。
