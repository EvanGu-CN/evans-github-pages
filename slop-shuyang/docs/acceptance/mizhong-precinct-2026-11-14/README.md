### 配准要点（新发现）

拼 13×13 瓦片时**拼图中心不在 (1664,1664)**，目标点真实像素为 (1590.2,1611.2)——按宽高一半取中心会整体偏 36.5 m E / 26.1 m N。本批先按错误配准误判"跑道偏移 50 m"，修正后 OSM 多边形与影像完全重合；模型原 TRACK 中心 (1281,-245) 是对的，错的是**轴对齐椭圆**形态。已改为按 OSM 角度旋转的"直道+两弯"体育场形。
