# 连续矢量路缘与沿街铺装 · 2026-11-15

本批解决斜向道路边缘的栅格锯齿：路面与路缘生成器共用相同转角三角形，陆地扣除车行道和有孔水面后形成500个矢量岛，保留45个内部道路/水面孔洞。它们替代原525个栅格岛；数量变化是计算拓扑变化，未新增或删除物理街道。旧栅格只继续提供保守地块矩形，66个不被新边界完全包含的辅助矩形被移除，不影响来源建筑。

上层铺装真实内缩0.3米；原算法向外偏移已移除。85个大于12万平方米的地块沿街生成3.3米窄带，沿街带合计约93.2万平方米，保留地块内部原有公园/地面表达。总共524个地表多边形、528个内缩铺装多边形。地图底色、行人边界、车辆路缘查询及地面高度同步使用有孔几何，三维不再把多边形包围盒整块视作人行道。

实景与精度说明见[研究记录](../../../tools/data/shuyang/vector-curb-research-20261115.md)。本批是全城通用几何修复，不是500处逐段实拍验收，未提升持续清单的道路证据状态。

## 验证

- 351项Node、2项Python编码测试通过；7项既有Overpass用例需要Bash，本机未运行，不计入通过数。
- 新增8项矢量路缘/交通测试，以及1项实际挤出函数孔洞传递检查，覆盖旋转/转角、全来源非退化路面三角形质心不进入路缘岛、内部孔洞、交通空间哈希保留多边形、大地块不整体铺装、来源记录不变、独立交通回路保留和全城区路网无终止路段。
- [全量几何审计](geometry-audit.json)：路缘岛与路面、水面、彼此之间的交叠均为0平方米；铺装越界0，最小内缩约0.2993米，差异为毫米量化误差。量化精度不代表现实测绘精度。
- [来源保留检查](source-preservation.json)逐字段对比前一来源提交：道路、来源ID、路网、步道、建筑、社区、水面、POI等23个字段均相同。仍为1,104条道路来源、1,105条渲染分段、7,741条建筑来源及92条步道。建筑二进制SHA-256保持`046c22fdec5cbfd2156a842b57643789abbc9f6248ac54b705b479e6c4a875a6`。

## 交通回归修复

精确路缘接入后发现：旧交通模型忽略小于12度的来源转折，会把较长缓弯拉成穿越路缘的直线；只保留最大强连通区域又会排掉其他城区仍有效的回路。本批保留更多来源折点，并改为反复剔除无后续出口的路段，保留所有有效循环及其可通行来路。每条保留车道都有后续路线，不代表不同回路之间已连通。

相同来源数据、不额外加入建筑障碍的离线比较：旧渲染/旧交通算法保留146条有向边；新路缘/新交通算法保留1,423条，覆盖北部与南部。比较是模拟图边数，不是实际道路数量；真实场景还按建筑障碍筛选，详见运行核验。未通过关闭路缘避让保留穿过铺装的车流。

## 实际浏览器

`runtime-audit.json`记录最终WebGPU场景：153个路面射线抽检点全部命中实际沥青网格，无路缘覆盖；真实建筑障碍参与筛选后有1,210条交通有向边，无缺少后续路线的边。台州路选定范围20条细分有向边均保留三个车道中心，数量因来源缓弯分段增加，不能当作新建道路。
