# 移动导航、中文界面与加速

- 小地图独立固定在左上方；触屏、窄屏和横屏均显示，避开摇杆、机位与加速控件。固定上北下南，显示中文四向与实时朝向，点击打开全屏地图。
- 修正原地图箭头多旋转 180° 的错误，使箭头与实际朝向一致。
- 右侧“加速”切换持续加速，按住上档键临时加速。四种移动方式均接入真实控制器，车辆和自行车加速时保持原有刹车与倒车规则；键盘和持续开关独立，松开上档键不会关闭已选中的持续模式。
- 界面、触屏提示、声音与隐藏界面提示、动作按钮、地图方向和计量单位改为中文；商铺纹理、广告牌及车辆地区文字同步替换。来源人名、注册号和许可标识保留正式写法。
- 骑行触屏增加中文刹车按钮。窄屏高度不足时省略浮动路牌，保持地图和摇杆清晰。

## 验证

217 项 Node 测试通过（0 失败），见 [tests.log](tests.log)。新增双上档键释放、输入框与失焦处理、持续 / 临时加速独立、四种移动方式速度差异及地图八方向测试。原有 7 项 POSIX Overpass shell 测试与本轮无关，沿用上一轮的 Windows 环境排除范围。

浏览器验证了持续加速的开关反馈、骑行刹车标签、点击小地图打开 / 关闭全图及上档键释放。320×568、375×667、844×390、1280×800 四种尺寸的小地图均在视口内，且不与工具栏、机位、加速、摇杆和出行方式栏相交。
