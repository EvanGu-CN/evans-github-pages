# 现代道路与建筑名称

## 改动

- 城区车行路面改用中性深灰沥青、小尺度颗粒和轻微湿润变化，移除旧路材质的大块棕色补丁、龟裂、坑洼和油污。人行道改用浅灰 600×300 mm 示意铺装，保留现有路缘几何。这是视觉材质调整，未声称每条道路近期都完成翻修。
- 修复标线 y=0.012 低于路面 y=0.03 的遮挡错误。普通道路标线位于 0.042，桥面标线位于 0.092；原始桥面没有实测高程，本轮未补造立交。
- 主路增加白色外缘线；同向虚线为 3 m 实段 / 6 m 间隔，双黄线加粗，降低标线磨损透明度。沿用真实路网生成方向、停止线和斑马线。
- 新增 120 条具名建筑 / 地点：学校 40、医疗 7、商业 8、公共管理 4、办公 6、文化 3、银行 1、车站 5、公园 7、其他具名建筑 39。三维按类别着色，地图 / 小地图显示名称并避让，名称可搜索。
- 位置区分源建筑与源地点，不把校园名称自动套到距离最近的某栋住宅上。原有 141 个住宅区标注保留。
- 全图搜索结果提供高德与百度官方搜索链接，按名称与沭阳县检索，未将 WGS84 坐标直接传入其他坐标系。

## 验证与限制

- 227 项 Node 回归测试通过，零失败，见 [tests.log](tests.log)。新增普通道路 / 桥面标线必须高于其路面、非住宅类型名称可检索、来源标识及外部地图搜索 URL 编码检查。
- 原有 7 项 POSIX Overpass shell 测试仍因 Windows 运行环境限制排除，与前一轮范围一致。后续标线透明度微调后，相关的 11 项道路 / 名称 / 启动检查再次通过。
- 空间检查通过，新增地表与楼体相交面积为 0，见 [geometry.json](geometry.json)。
- 使用与页面一致的 Three.js 0.187.0，在 Node 中实际构造并序列化新沥青 / 人行道 TSL 节点图，结果见 [materials.json](materials.json)。这不替代 GPU 着色器编译和视觉验收。
- 本轮未完成新版浏览器视觉验收。内置浏览器尝试打开高德后读取连续超时；随后 Windows computer-use 工具因无法可靠确认当前 Chrome 网页地址而中止，要求停止浏览操作。没有继续用其他浏览自动化绕过限制，也未获取高德 / 百度实景或新楼高。
- 高德、百度 API 官方文档可访问，程序化地点查询需要相应 Key / AK；当前未配置并使用商业地图数据。官方链接只用于用户打开公开地图核对。

本地已有 8123 服务保持运行；修改保存在工作区，未提交或部署到远端。
