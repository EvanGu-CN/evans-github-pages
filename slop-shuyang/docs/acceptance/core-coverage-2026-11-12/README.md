# 核心楼体覆盖与社区入口 · 2026-11-12

本轮修复来源楼体被地标整栋误删的问题，细化商场真实占地，新增两处核心商业楼模型，并开始小区入口实拍建模。完整目标仍在推进，见 [持续还原进度](../../BUILDING_REFINEMENT_PROGRESS.md)。

## 覆盖修复

之前普通楼体保留7,530条，28条因替换/相交删除。现在保留7,542条，15条与具体源ID绑定的专用替换，1条完全被模型占用。13条部分重叠楼体只扣除实际模型占地，保留约9,822.2㎡的剩余占地与内院；裁剪失败0。统计见 [运行时覆盖](runtime-coverage.json)。两处新增定制楼也已纳入明确替换，不能把普通楼体增量误读为全部新增建筑数。

几何差集采用固定版本polygon-clipping 0.15.7，随项目本地加载；授权与依赖声明见 [第三方许可](../../../js/vendor/polygon-clipping-LICENSE.md)。原始7,558条来源数据、顺序、名称关联和高度来源未被改写。

检查确认：Overture/OSM去重在当前快照未出现“部分重叠但整条丢弃”的剩余缺口，因此没有为了增加数量调整融合阈值。缺失的一项来源是渲染端的整栋剔除：中央商场原36,296㎡轮廓仅由约10,396㎡模板占地替代，蓝天约54,428㎡只覆盖约21,895㎡，万达约37,897㎡只覆盖约15,958㎡。这些是二维占地比较，不是楼面面积。现三处商场直接使用完整源轮廓；中央主塔也回到来源坐标。

县政府大轮廓覆盖院区、体育场大轮廓含开放球场，不能为了覆盖率恢复成整块高楼。它们保留专用替换并列为进一步细化对象。吴印咸故居及车站仍使用已核对的专用模型。
