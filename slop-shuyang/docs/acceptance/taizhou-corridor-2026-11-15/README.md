# 台州路道路与景观断面 · 2026-11-15

依据[施工单位标准断面、通车后航拍与沭阳发布实景](../../../tools/data/shuyang/taizhou-road-research-20261115.md)，将珠海路—杭州路之间三条既有主路来源从推定16米/五车道改为21.5米/双向六车道。界外道路与辅路保留原断面，原1,104条道路way成为1,105条渲染分段，未新增物理道路。

新增两侧绿化分隔带、非机动车道、景观长廊、2.5米步行带与路缘，共277个裁切地表多边形；三维和矢量地图使用同一几何。绿化候选421处，运行时经建筑避让和树间去重选入408处，再交由既有树场检查；该数量是展示布点，不是实际植株调查。全部来源建筑、水面、既有机动车/辅路、已知广场地面均参与避让。原7,741条建筑来源与二进制不变。

加宽后检测到旧城市地表仍覆盖约272.168平方米车行道，已修正城市地表生成器：直接读取同一断面元数据进行裁切，并为既有简化误差预留1.5米保护距离。这个距离用于地表避让，不扩大21.5米路面。

## 精度与后续

证据来自2022年报道，拍摄日未知，不称作2026现状。标准断面不能代表每个路口的竣工形态；粉色铺装、树种/数量、绿化退让与路缘尺寸仍属展示估计。没有把无法定位的航拍建筑绑定到具名楼体，也没有新增猜测的公交站。局部中分带、转向车道、渠岸、道路设施与沿线建筑继续逐段核对，全城区持续目标未完成。
