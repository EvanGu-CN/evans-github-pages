## 数据和密钥

本次高德Web/JS API查询成功，公开结果在 [landmark-amap-observations.json](../../../tools/data/shuyang/landmark-amap-observations.json)。6次有效查询区分了上海南路店与台州南路店、本部与东校区。馆群和两座商场沿用WGS84来源轮廓；高德GCJ-02点位反算为WGS84后转成本项目米制坐标，反算不代表测绘精度。

安全密钥只用于127.0.0.1临时代理进程内存，未进入浏览器前端、源码、数据或验收日志。Key也未写入交付文件。临时8124代理已关闭；8123本地静态预览服务运行中。静态漫游读取留存的公开数据，运行时不需要高德密钥。

普通建筑仍有CNBH2020遥感估高和用途估高，不能由本次地标照片更新推导为全城2026实测建筑。没有照片依据的背面、入口和尺寸保留近似说明。

## 验收

- 231项Node测试通过，见 [tests.txt](tests.txt)。7项依赖POSIX shell的既有Overpass工具测试在Windows未执行。
- 新增检查：来源替换索引与OSM ID对应；高中来源校园不被整体替换；三个新增入口朝向、距离和干燥落点；15处参考图的来源与署名覆盖。
