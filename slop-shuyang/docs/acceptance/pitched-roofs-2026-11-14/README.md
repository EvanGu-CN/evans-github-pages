# 双坡屋顶实体渲染 · 2026-11-14

旧渲染器虽然读取`gabled`标记，但最终仍绘制平顶。本批让全部71条已有双坡来源生成142片裁切平面：沿来源长轴起脊，在两侧平面内分别三角化，补闭合山墙，保留凹口、洞和全部来源轮廓。总高度继续包含屋面，未在原高度上额外加坡。屋脊与瓦缝增加按米组织的抗锯齿材质；平屋顶与既有四坡顶保持原材质。

坡顶不再继承平顶专用的水平檐线和随机屋顶设备，避免出现悬浮在屋脊高度上的构件。原始7,741条建筑来源、轮廓、高度、碰撞边界及二进制未改变。

本批是渲染器修复；双坡标签、坡高、最小外接矩形推定的屋脊方向、瓦材尺寸仍是原有或本批展示估计，不代表71栋都已按现状实拍还原。部分轮廓包含相接体块，也不能将71条来源称为71栋实测建筑。[本轮研究记录](../../../tools/data/shuyang/core-roof-research-20261114.md)保留新增实景查看及尚未解决的图片对应问题。

## 验证

- 新增5项测试覆盖：任意旋转、凹口/院落、所有71条来源面积守恒、实体网格坡度与绕序、坡顶附件兼容。
- 332项Node及2项Python编码测试通过；7项既有Overpass测试需要Bash，本机未计入通过数。来源二进制SHA-256仍为`046c22fdec5cbfd2156a842b57643789abbc9f6248ac54b705b479e6c4a875a6`。
- [几何清单](../../refinement/roof-coverage.json)逐条记录来源、总高、坡高、轴向和投影覆盖面积；没有“完成实景还原”状态。
- 实际浏览器的142个坡面探测点均命中预期坡顶，高度误差小于0.01米；这是程序几何校验精度，不是模型对真实建筑的测量精度。详见`roof-ray-audit.json`。
- `junlin-day.png`、`junlin-close.png`及幸福家园日夜景为实际WebGPU画布导出，不含HUD；渲染后端`WebGPUBackend`、控制台错误0，临时相机与缓存设置已恢复。
