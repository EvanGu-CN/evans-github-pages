# 小区标名、街道与最新开放数据

本轮延续城区还原，未扩展仿真边界，未提交或发布到远端。

## 结果

- 开放地图道路、建筑快照更新到北京时间 2026-11-12 00:04，用地更新到 00:08。查询南界补至 34.08°，覆盖原先漏采的城区南段；旧镜像数据会被拒绝，网络失败保留本地较新快照。
- 141 个真实具名住宅区进入地图、小地图、三维导航标注及当前位置提示。全名、部分名称和来源别名可以搜索，搜索结果高亮真实边界，显示收录楼栋数。
- 2,934 栋建筑按实际多边形覆盖率关联小区；嵌套分期优先较小范围、每栋只关联一次，文件 SHA-256 防止建筑顺序变化导致错配。同一小区住宅使用统一立面变体。
- 68 段来源步道、4 处停车场和 1 处花园面进入三维场景；住宅用地采用统一底色。楼体、车行路面和水面从新增地表中扣除。未虚构内部道路或围墙。
- 修正街道带状网格的三角形朝向，恢复从上方可见的沥青路面；公园树木限定在真实多边形内，并避让道路和步道。
- 源建筑仍为 7,558 栋，其中 OSM 1,425、Overture 6,133；刷新后部分 Overture 重复建筑由 OSM 优先替代，总数没有虚增。

## 验证

224 项 Node 测试通过，零失败，见 [tests.log](tests.log)。覆盖名称 / 别名搜索、当前位置、建筑索引绑定及唯一分配、地表有效性、住宅风格一致性、道路所有朝向的正面可见性、凹多边形种树和步道避让。原有 7 项 POSIX Overpass shell 测试因 Windows 缺少对应运行环境，沿用上一轮排除范围。

`tools/audit-shuyang-urban.py` 另对全部小区锚点、楼栋关联覆盖率、地表多边形有效性和新增地表与楼体相交面积进行空间检查，结果见 [geometry.json](geometry.json)。

浏览器验证了巴黎新城的范围高亮、73 栋建筑反馈、传送后的当前位置、小地图名称，以及高空机位的三维小区导航标签。375×667 窄屏验证了南部观澜府的名称搜索、10 栋建筑反馈和范围显示，建议名称列表共 141 项。最终页面没有应用运行错误。

## 仍有的还原限制

快照日期代表开放数据库时间，不代表每栋建筑刚完成实测。部分新小区已有名称但缺少楼栋轮廓；不能凭小区范围造楼。5,271 栋高度来自 2020 年 CNBH-10m 模型，2,286 栋仍为用途估高；不能据此保证最新高层天际线。外墙颜色、窗型和小区铺装尚未逐栋照片核实，统一配色和用地底色属于展示估计。三维名称是导航标签，不是实体楼顶招牌。

来源、许可与重建步骤见 [BUILDINGS.md](../../../tools/data/shuyang/BUILDINGS.md)。
