# 久盛百货西广场与临街界面 · 2026-11-14

## 范围与证据

在人民路×上海路东北角的既有久盛主盒楼 `way/1367632165` 上细化，来源轮廓、建筑记录总量和估高不变。

网络检索后，重新打开[沭阳发布 / 我苏网 2019-09-29 图文](https://www.ourjiangsu.com/a/20190929/1569742645931.shtml)，下载并实际查看五张街景与夜景；[逐图记录](../../../tools/data/shuyang/jiusheng-photo-research-20261114.md)。2019 为发布年，拍摄日未单列，未称为 2026 现状。

## 渲染变化

- 南、西两个有照片的临街面：首层门窗竖梃及横楣、突出招牌带、广告框与空屏、三层檐口、百叶分段立柱；保留蓝玻璃转角，减小既有名称牌以避开广告框。
- 西广场：按来源西墙旋转的深灰铺装、入口红色铺地带、石材分缝、三条波纹嵌地灯带。
- 临街设施：三组石材花池、木条座面、两座高低错落的蒲公英灯饰；每球 56 根独立金属辐条与种子头，不使用实心发光球。
- 参考面板增为三张署名照片，明确历史时点与尺寸估计；未将历史租户标志复制为当前商户。

模块 `js/jiusheng-precinct.js` 由久盛专用模型调用，沿用静态材质合批，细节不新增楼体碰撞。

## 验证

- 316 项可在 Windows 直接运行的 Node 测试全部通过，日志 `node-tests.txt`；2 项 Python 测试通过。
- 另有 7 项既有 `overpass.test.mjs` 需要 Bash，本机无 Bash，未计入通过数；此前全量尝试均报 `spawnSync bash ENOENT`。
- 新增 4 项回归：广场构件四角避开真实道路宽度和楼体轮廓；只细化南/西立面；辐条与灯头数量/坐标有限；历史日期及来源完整。
- 浏览器使用本机原生渲染，检查近景、夜景与参考面板；截图和运行数据保存在本目录。固定验收相机只作用于临时预览，结束时恢复。
- 实际后端为 `WebGPUBackend`；久盛整组模型合批后 20 个网格、30,268 个顶点，控制台错误 0。`native-day.jpg` / `native-night.jpg` 为本机画面，`runtime-audit.json` 保留范围与来源元数据。参考图面板实测为 3 张，第二张原图成功加载，600 像素原宽，来源与年份可见。

## 精度边界

广场进深、窗格/广告尺寸、灯饰高度和具体设施落位均为展示估计。道路标线、车道数与中心线保持来源数据；未把未核实的护栏公告或道路设计效果图当作沭阳已建状态。
