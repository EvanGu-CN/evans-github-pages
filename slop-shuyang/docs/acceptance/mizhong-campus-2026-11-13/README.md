## 校园来源楼体角色判定

23 栋按质心匹配 `REAL_BUILDINGS`，角色由位置、体量、层高与游记轴线索引综合判定：

| 角色 | 栋数 | 判据 |
|---|---|---|
| 育华楼（行政/主教学） | 1 | 校门正北，游记"最中心教学区"，实景山花+金字 |
| 大礼堂 | 1 | 育华路以西，1961 年官方影像青砖坡顶 |
| 老建筑（行知楼一类） | 1 | 校园西南角，体量小 |
| 教学楼（外廊式） | 5 | 灰面砖+外廊实景，14–18 m 层高 |
| 教学楼群（培源/培根、振宁/振道） | 2 | 102×93、74×68 大型组合体，游记集群描述 |
| 低层大跨度（科技楼/活动中心） | 4 | h=9 m，大体量 |
| 体育馆/看台 | 1 | 贴操场，54×76 |
| 食堂 | 2 | 北侧大体量，8400 m² 供 3000 人 |
| 宿舍楼 | 5 | 北侧行列式，18 m 层高 |
| 服务用房 | 1 | 贴操场东侧小体量 |

**注意**：楼宇名称是综合推断，不是逐栋测绘。没有来源照片的楼栋只做类型化外廊/窗带，不贴楼名。

## 精度声明

- **来源轮廓**：23 条全部保留，一条不改、一条不加。
- **已核实**：山花/金字/泰山石/大礼堂坡顶/跑道位置——有实景或官方影像。
- **类型化估计**：窗格排布、层数推算（高/3.1 m）、阳台排数、空调机位——按同类型建筑估算。
- **未核实**：育华楼两翼层数是否均为 5 层；大礼堂是否仍作礼堂使用（游记未提）；体育馆/看台实际分界。
