# 政府、体育中心与社区补充验收

本批继续城区还原，没有完成全城逐栋现状核对。保持17处可传送地标及原有出行方式、小地图、中文界面、加速功能。

## 本批可见变化

- 县政府：主塔移到真实主楼中央约(2335,1748)，沿来源斜向布置；低翼保留真实六点轮廓，西侧附楼使用独立来源屋顶和缓四坡大屋顶。院区空地不挤高。
- 体育中心：主场移至约(-489.25,4722.5)，68×105米足球场长轴南北；东西看台分开，保留南北通道，折板屋盖和V形构架。西北体育馆、西南游泳馆分别沿来源单体重建与命名。
- 社区：新增紫藤花园曲梁入口、东方明珠城题名景石，门址均为来源服务道路与小区边界交点的近似照片关联。宁浦·冠城具名题名墙照片保留，门址尚未确认。
- 141个小区公开高德查询完成；131个名称/位置匹配，127个取得候选图片，共309张，已排除一张上海陆家嘴误配图。7个小区已核对入口照片，4个入口局部落地；候选图显示未核验状态，不自动生成模型。

## 验证

- Node测试244项通过（Windows不运行既有POSIX shell专用的7项Overpass测试）；另有2项Python UTF-8管道/非法代理字符回归测试通过。
- 几何回归验证政府主塔位置、开放广场、球场/南北通道、东西看台、独立体育馆/游泳馆及干燥无墙传送落点。
- 浏览器实际17处地标的安全落点均无水面/楼体重叠；中央商场候选点由既有安全落点逻辑平移4米，其余无需调整。露天球场中心在1/8/20米高度均无楼体覆盖，详见同目录runtime-audit.json。
- 来源记录7558；普通楼体7538，明确专用模型替换19条，完全覆盖1条；13条部分裁剪，裁剪失败0。新增4条专用替换对应真实院内楼体，不是删楼。
- 本地真实浏览器检查模型、照片面板及手机布局，截图保存在同目录。后台浏览器的帧率显示不作为性能测量。

## 证据与边界

- [政府/体育院区证据](../../../tools/data/shuyang/civic-campus-photo-research.md)：政府2024年公开航拍，体育中心2026年公开航拍与带北箭头图；发布日不冒充拍摄日，临时演出设施不建为永久建筑。
- [小区逐图核验](../../../tools/data/shuyang/community-amap-photo-review.md)：实际查看8张，确认3处具名入口局部，排除1张异地照片。全部3张入口照片拍摄日期未知。
- [高德地点匹配清单](../../../tools/data/shuyang/amap-community-context.json)：GCJ-02先近似转WGS84，再核对小区边界；POI中心不作为入口坐标。
- 主塔/屋盖高度、内场和入口尺寸仍为照片比例估计。多数普通楼体高度仍来自2020遥感，未逐栋更新到2026实测；134个小区入口仍待核图。

凭据只经内存和stdin交给本地临时高德代理，不存入源码、配置、截图或公开数据；采集代理已关闭。
