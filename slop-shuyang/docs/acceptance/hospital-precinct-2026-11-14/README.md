本批增加塔楼南/西侧窗带、白色竖向墙带、红字院名与玻璃冠部；裙楼浅青幕墙、分格、开窗、石材入口框架和屋面设备；上海中路一侧补细铺装接缝、台阶、绿色候车棚及座椅。构件数量与尺寸为展示估计。未使用历史等级、合作医院、药房租户、公交线路或广告文案。
