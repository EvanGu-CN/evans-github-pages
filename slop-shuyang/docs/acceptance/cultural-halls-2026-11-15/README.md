# 两馆主体、屋顶与前场 · 2026-11-15

博物馆和图书馆此前将包含场地的来源四边形整块挤出。本轮按可见影像缩回主体：图书馆约4522平方米、博物馆约3580平方米，分别为来源地块的32.1%和38.5%。恢复前场铺装及四块近似绿地，地图、主体和碰撞使用同一组轮廓。原来源几何/高度与建筑二进制保留。

图书馆按2024年建成鸟瞰重建推定西向主立面的错位窗带、两组内凹玻璃、入口和竖排题名，补带框架的中央采光顶。博物馆按具名实拍补南侧折角门框、玻璃和石材分格，校准折面屋盖与蓝色半球落点。19.0/15.3米为展示顶高，来源15/11.7米不变。详见[实景与影像研究](../../../tools/data/shuyang/cultural-halls-photo-research-20261115.md)。

## 尚未完成

照片拍摄日与卫星影像采集日未知。屋顶范围有人工描图与视差，西向主立面是周边关系推定，其他立面、精确高度、停车、楼梯与植物仍未逐项验证。图书馆南侧的独立建筑已记录为待补来源候选，未套用两馆身份。全城逐栋、逐街段目标继续保留，不因两馆验收而宣称完成。
